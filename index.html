Sheet tab format — Orders: Orders CSV wahi headers (Reason for Credit Entry, Sub Order No...). PreviousPayment / OutstandingPayment / AdsCost: Meesho payment file ke respective sheet ka data waise hi paste karo jaisa Excel me dikhta hai (3 header rows sahit — Previous file ka "Order Payments" sheet PreviousPayment tab me, Outstanding file ka "Order Payments" sheet OutstandingPayment tab me). RateCard: columns SKU, Product, Cost Price. ExtraExpenses: columns Date, Category, Description, Amount. (Ya seedha Sheet ke andar wale "📊 Raj Meesho" menu se "One-Time Setup" chala ke sab tabs auto-ban jayenge.)
